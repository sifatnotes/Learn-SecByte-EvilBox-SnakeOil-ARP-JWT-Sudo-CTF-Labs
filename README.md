# Learn SecByte EvilBox, SnakeOil, ARP, JWT & Sudo CTF Labs

Hands-on cybersecurity and CTF lab collection covering ARP discovery, beacon hunting, VirtualBox networking, EvilBox reconnaissance, hidden entry points, SnakeOil attack-chain analysis, JWT relay concepts, Linux enumeration, sudo escalation, and root-access scenarios.

Designed for cybersecurity students, CTF players, penetration testers, SOC analysts, and security learners practicing authorized security testing.

## Introduction

This collection combines network reconnaissance, virtual lab discovery, EvilBox exercises, and SnakeOil Linux security scenarios.

The labs progress from discovering network hosts and understanding a controlled VirtualBox environment to investigating attack chains, authentication-related concepts, Linux enumeration, sudo configuration, and privilege escalation.

Use these exercises only against intentionally vulnerable or explicitly authorized systems.

## Learning Path

A practical progression through this collection is:

1. Start with **VirtualBox NetLab Secrets** to understand the controlled network environment.
2. Practice discovery with **ARP Ambush Discovery Lab** and **Beacon Hunt**.
3. Continue with **EvilBox Lab Launchpad** for target-oriented reconnaissance.
4. Explore **Shadows in the Secret** and **EvilBox Hidden Entry** for hidden-resource discovery.
5. Study **SnakeOil Review: The Attack Chain** to understand how findings can connect.
6. Explore **SnakeOil JWT Relay** for authentication and JWT security concepts.
7. Move into **SnakeOil Secrets: Linux Enum to Root** for systematic Linux enumeration.
8. Study **Sudo Sleight** and **SnakeOil Sudo Escalation** for sudo-related security concepts.
9. Finish with **SnakeOil Rootchain** to review Linux privilege-escalation concepts.

## How to Use the Labs

1. Select a lab from the direct-link index.
2. Confirm that the target belongs to an authorized training environment.
3. Read the lab objectives and understand the permitted scope.
4. Begin with reconnaissance and information gathering.
5. Document hosts, services, configurations, authentication mechanisms, and other findings.
6. Test techniques only against the intended lab target.
7. Record your methodology and evidence.
8. Review possible defensive controls and mitigations after completing the exercise.
